READING THE MODEL
這不是單一路徑預測
最佳應變策略是一棵樹：每投一球，就依打者的壞球、看好球、揮空或界外反應選下一球。三振、保送與打進場則是終點。
模擬策略使用同一個模型與 10,000 個打席，因此可以橫向比較；「實際」列則完全來自 Statcast 真實打席，樣本數會顯示在策略名稱裡。
